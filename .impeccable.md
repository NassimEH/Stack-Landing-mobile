## Design Context

### Users
Apprenants tech (débutants à intermédiaires) qui veulent monter en compétence sur le réseau, le web et le logiciel via des sessions courtes type Duolingo — sur mobile, en solo, avec progression gamifiée (XP, streaks, défis, labs).

### Brand Personality
Ludique, clair, ambitieux — « le Duolingo de la tech ». Confiance sans jargon intimidant ; encouragement à progresser un peu chaque jour.

### Aesthetic Direction
Landing adaptée d’un template app mobile existant : structure conservée, identité Stack (bleu `#2563EB`, fond clair teinté slate/bleu, logo + mascotte). Anti-références : thème food/delivery, orange fast-food, purple-glow AI slop, dark neon cyber. Typo Lexend (titres) + Manrope (corps).

### Design Principles
1. Brand first : le nom Stack et le tagline dominent le premier viewport.
2. Une section = un message (parcours, pourquoi, features, how-to, FAQ, download).
3. Visuels produit réels (logo, icône, mascotte) plutôt qu’images stock food.
4. Légal & trust visibles : privacy / terms / support liés pour stores.
5. Conserver le rythme du template (motion AOS, typed text) sans clutter restaurant.
